JEAN GONZAGA — VA PORTFOLIO

FILES
- index.html: complete responsive portfolio website in one file.

BEFORE PUBLISHING
1. Open index.html and replace YOUR_EMAIL_HERE with your professional email address.
2. Review every work sample and add your actual screenshots, links, or files before presenting them as evidence.
3. Keep labels such as Practice Project, Training / Internship Sample, and Personal Project so the portfolio stays transparent.
4. You can edit the text and add more project cards inside the section with id="projectGrid".

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository named: jean-portfolio (or your preferred name).
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish your site. The URL will look like:
   https://YOUR-USERNAME.github.io/jean-portfolio/

This is a static website. GitHub Pages hosting is free, subject to GitHub's plan limits.
